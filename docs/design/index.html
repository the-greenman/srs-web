The governance editor, in paper and ink.

A modular, reusable CSS system for the SRS governance web editor — extending the muDemocracy design language into an application shell. No accent colour; hierarchy comes from weight, size, and mono/sans contrast.

Design decisions

  • No accentStatus and severity are signalled by fill, border style, and weight — never hue. Errors are ink-filled chips; superseded records strike through; drafts use a dashed border.
  • Mono = systemEvery label, id, count, and piece of metadata is IBM Plex Mono. Human prose is IBM Plex Sans. The contrast does the wayfinding.
  • Layered cascadetokens → base → layout → components → utilities, locked with @layer. Order is independent of import order.
  • BEM blocksEach component is a self-contained .block__element--modifier file, reusable in isolation and mapped to its Track B issue.
  • Tokens onlyComponents reference custom properties, never literal colours or sizes. A rebrand is a single-file change in tokens.css.
  • Thin clientPer ADR-001 these styles only render what the WASM engine produces — no SRS semantics live in the presentation layer.
